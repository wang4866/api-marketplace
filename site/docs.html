Web2MD API Docs

REST API for converting webpages to clean Markdown. Free tier available — no API key required.

Base URL: https://web2md.onrender.com

Overview

The Web2MD API accepts a URL, fetches the webpage, extracts the main content (stripping ads, nav, footers), and returns clean Markdown. Perfect for:

  • 📚 Content aggregation and research
  • 🤖 AI/LLM training data pipelines
  • 📝 Blog and article backups
  • 🔍 SEO content analysis

API Endpoints

POST /convert
Convert a webpage URL to clean Markdown

Request Body

FieldTypeRequiredDefaultDescription
urlstring✅—The full URL of the webpage (must start with http:// or https://)
include_imagesboolean❌falseInclude image markdown references in output

Response (200 OK)

FieldTypeDescription
successbooleanAlways true on success
titlestringPage title from HTML <title> tag
contentstringClean Markdown output of the main content
urlstringThe original URL (echoed back)
word_countintegerWord count of the markdown content
char_countintegerCharacter count of the markdown content

Error Response (4xx/5xx)

FieldTypeDescription
detailstringError description

Rate Limiting

Free tier: 100 requests per hour per IP address. Rate-limited requests return HTTP 429.

Code Examples

curl

curl -X POST https://web2md.onrender.com/convert \
  -H "Content-Type: application/json" \
  -d '{"url": "https://en.wikipedia.org/wiki/Markdown"}'

Python

import httpx

resp = httpx.post("https://web2md.onrender.com/convert", json={
    "url": "https://en.wikipedia.org/wiki/Markdown"
})
data = resp.json()
print(f"Title: {data['title']}")
print(f"Words: {data['word_count']}")
print(data['content'])

JavaScript (Node.js)

const resp = await fetch("https://web2md.onrender.com/convert", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ url: "https://en.wikipedia.org/wiki/Markdown" })
});
const data = await resp.json();
console.log(data.title, data.content);

With Images Included

curl -X POST https://web2md.onrender.com/convert \
  -H "Content-Type: application/json" \
  -d '{"url": "https://en.wikipedia.org/wiki/Image", "include_images": true}'
