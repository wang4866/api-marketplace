API 文档

Web2MD API — 把任意网页URL转为干净Markdown

基本信息

基础URL：http://localhost:8000
格式：JSON
方法：POST
限流：100次/小时/IP

接口列表

POST /convert

把网页URL转为干净Markdown。

请求参数：
{
  "url": "string (必填)",          // 要转换的网页URL
  "include_images": false (选填)   // 是否保留图片链接，默认false
}
返回结果：
{
  "success": true,                 // 是否成功
  "title": "网页标题",              // 提取的标题
  "content": "# Markdown内容...",   // 干净的Markdown正文
  "url": "https://...",            // 原始URL
  "word_count": 1234,              // 字数
  "char_count": 5678               // 字符数
}
GET /health

健康检查。返回 {"status": "healthy"}

GET /docs

Swagger UI 交互式文档。

使用示例

curl（命令行）

curl -X POST http://localhost:8000/convert \
  -H "Content-Type: application/json" \
  -d '{"url": "https://zh.wikipedia.org/wiki/Markdown"}'

Python

import httpx

resp = httpx.post("http://localhost:8000/convert", json={
    "url": "https://zh.wikipedia.org/wiki/Markdown"
})
data = resp.json()
print(data["title"])
print(data["content"])

JavaScript

const resp = await fetch("http://localhost:8000/convert", {
  method: "POST",
  headers: {"Content-Type": "application/json"},
  body: JSON.stringify({
    url: "https://zh.wikipedia.org/wiki/Markdown"
  })
});
const data = await resp.json();
console.log(data.title, data.content);

错误处理

400 URL格式错误或无法访问 — 检查URL是否正确
429 请求太频繁，超过每小时100次限流 — 等待后重试
500 服务内部错误 — 重试或联系开发者

部署指南

项目开源，可以一键部署到任何平台：

Render push到GitHub → Render自动检测render.yaml → 自动部署
Railway 导入GitHub仓库 → 设置启动命令: uvicorn app.main:app --host 0.0.0.0 --port $PORT
VPS 拉取代码 → pip install -r requirements.txt → uvicorn app.main:app
