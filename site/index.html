适用场景

        

            

                
🤖 AI训练数据采集

                
批量抓取网页，提取纯净文本内容用于LLM训练、RAG知识库构建。

                

                    
import httpx

urls = ["https://zh.wikipedia.org/wiki/机器学习"]
for url in urls:
    resp = httpx.post("http://localhost:8000/convert", json={"url": url})
    data = resp.json()
    with open(f"corpus/{data['title']}.md", "w") as f:
        f.write(data["content"])

                

            

            

                
📝 笔记收藏

                
一键将网页文章保存到Obsidian、Notion、飞书知识库，格式完美。

                

                    
curl -s -X POST http://localhost:8000/convert \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/article"}' \
  | jq -r '.content' > 我的笔记.md

                

            

            

                
📊 SEO分析

                
分析竞品文章结构、字数、标题层级，获取机器可读的结构化数据。

                

                    
curl -s -X POST http://localhost:8000/convert \
  -H "Content-Type: application/json" \
  -d '{"url":"https://competitor.com/post"}' \
  | jq '{字数: .word_count, 标题: .title}'

                

            

            

                
📡 内容聚合

                
搭建RSS阅读器、新闻聚合站、每日简报，统一内容格式。

                

                    
async function saveArticle(url) {
  const resp = await fetch("http://localhost:8000/convert", {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({url})
  });
  return await resp.json();
}

                

            

        

    


    
    

        
常见问题

        

            

                支持中文网页吗？
                
支持。基于BeautifulSoup智能提取，中文、英文、日文等各类语言的网页都可以处理。

            

            

                免费额度是多少？
                
每个IP每小时100次请求，完全免费，无需注册。

            

            

                怎么部署到自己的服务器？
                
项目开源在GitHub，支持一键部署到Render、Railway或自己的VPS。详见GitHub README。

            

            

                响应速度如何？
                
一般在500ms-2s内返回，取决于目标网页大小。部分动态页面可能较慢。
