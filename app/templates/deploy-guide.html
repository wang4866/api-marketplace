🛤️ 方案一：Render 一键部署（推荐）

1 注册 Render 账号

访问 render.com → 用 GitHub 登录

2 新建 Web Service

Dashboard → New + → Web Service

Connect repository → 选择 wang4866/api-marketplace

或者手动指定: https://github.com/wang4866/api-marketplace

3 填写配置 
Name: api-marketplace
Runtime: Python 3
Build Command: pip install -r requirements.txt
Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT
Instance Type: Free
4 设置环境变量 
OLLAMA_BASE: https://your-ollama-server.com:11434

⚠️ Chat Proxy 和 Embeddings 需要连接一个远程 Ollama 实例。

选项：

  • 在同一台 Render 上部署 Ollama（需要 Docker compose）
  • 使用自己的服务器上跑 Ollama，暴露 API
  • 暂时只上线 Web2MD（不需要 Ollama）
5 部署

点击 Deploy → 等 2-3 分钟 → 上线！

你的 API 地址: https://api-marketplace.onrender.com

🛤️ 方案二：Railway 部署

🛤️ 方案三：RapidAPI 上架

RapidAPI 可以让开发者发现和购买你的 API。

1. 注册 rapidapi.com

2. 进入 Provider Dashboard → Add New API

3. 上传 OpenAPI 规范：

curl http://localhost:8000/openapi.json > openapi.json

4. 设置定价方案，参考已有方案：

Free: 100 次/天
Starter: $9.99/月 - 1000 次/天
Pro: $29.99/月 - 10000 次/天
Enterprise: $99.99/月 - 无限制

🔧 本地管理

# 本地已运行
curl http://localhost:8000        # API 根
curl http://localhost:8000/admin  # 管理面板
curl http://localhost:8000/health # 健康检查

# 创建 Pro API Key
curl -X POST http://localhost:8000/key/create \
  -H "Content-Type: application/json" \
  -d '{"tier": "pro", "email": "user@example.com"}'

# 测试（替换为你的 key）
curl -X POST http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-API-Key: w2md_xxxxxxxxxx" \
  -d '{"model": "qwen2.5:7b", "messages": [{"role":"user","content":"你好"}]}'
